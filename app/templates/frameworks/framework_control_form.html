About requirements

A requirement is a single control objective from the framework — one clause, one control statement, one annex item.

Give it a recognisable code so auditors and control owners can reference it, for example:

  • ISO/IEC 27001 — A.5.1
  • NIST CSF — ID.AM-1
  • SOC 2 — CC6.1
  • PCI DSS — Req 8.3

Once saved, map your internal controls to this requirement to build coverage.
