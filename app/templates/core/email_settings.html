Quick presets

Local Ubuntu Postfix

  • Host: your VM IP (e.g. 192.168.56.10)
  • Port: 25
  • Encryption: None
  • Username/password: blank
  • From: no-reply@everest.local

Gmail / Google Workspace

  • Host: smtp.gmail.com
  • Port: 587, STARTTLS
  • Username: full address
  • Password: an App Password

Mailtrap / sandbox

  • Host and port from the sandbox inbox
  • STARTTLS, username and password from the inbox
Before you enable
  • Confirm the SMTP port is reachable from the web container.
  • If the relay authenticates, enter the username and password.
  • Use a From address the relay is allowed to send for.
  • Send a test, then check the recipient inbox and spam folder.
  • The full setup guide is in docs/EMAIL.md.
