## Contributing

This project is currently **under academic assessment** and does not accept external contributions.

Once the assessment period concludes and the project moves to open-source, contribution guidelines will be published here.

## How to contribute (post-assessment)

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes (`git commit -m 'Add some feature'`)
4. Push to the branch (`git push origin feature/your-feature`)
5. Open a Pull Request

All contributions will be reviewed for:
- Code quality and consistency
- Test coverage
- Documentation updates
- Adherence to the existing architecture
